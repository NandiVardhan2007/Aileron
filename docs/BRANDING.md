# Branding — Aileron

## Why "Aileron"
An aileron is the control surface that **rolls** an aircraft. In Aileron the app, **rolling your hand is the
steering input**. The word is short, aviation-flavored, pronounceable (*AY-luh-ron*), and fits a product
that grows from "mouse" to "flight deck".

> Trademark note: other companies use "Aileron" in unrelated fields. Run a trademark and domain search
> before public launch; fall back to the shortlist below if needed.

## Shortlist

| Name | Meaning | Vibe | Risk |
|------|---------|------|------|
| **Aileron** (chosen) | Wing control surface; roll | Precise, technical, cool | Existing unrelated companies |
| Contrail | Trail left by aircraft (your hand's trail) | Poetic, visual | Common word |
| Yoke | Aircraft control column | Short, punchy | Too generic, hard to search |
| Stratus | High-altitude cloud layer | Calm, airy | Many existing products |
| Pitot | Airspeed sensor | Nerdy, unique | Hard to pronounce for many |
| Gyrfalcon | Fastest falcon | Fast, sharp | Long, existing chip company |

## Taglines
- *Fly your cursor.* (primary)
- *Your hands are the controls.*
- *Touchless. Precise. Cleared for takeoff.*

## Vocabulary

| Term | Meaning |
|------|---------|
| **Pointer mode** | Mouse replacement |
| **Cockpit mode** | Simulator control via virtual gamepad |
| **Yoke / Handlebar / Stick** | Cockpit profiles (car wheel / bike / flight) |
| **Armed / Disarmed** | Whether output is being sent to the OS |
| **Standby** | Armed session paused by the clutch gesture |
| **Pre-flight** | The calibration wizard |
| **HUD** | On-screen overlay showing tracking state and gesture feedback |
| **Kill switch** | Global hotkey that stops all output instantly |
| **Black box** | Ring buffer of recent landmarks for fault analysis (opt-in, never video) |

## Visual identity (brief)
- **Palette:** Deep navy `#0B1220`, signal cyan `#19D3F3`, amber caution `#FFB020`, go-green `#2EE59D`, alert red `#FF4D5E`.
- **Type:** Inter (UI), JetBrains Mono (HUD readouts).
- **Logo concept:** A swept-wing silhouette whose leading edge is formed by the five-finger landmark skeleton; works as a monochrome icon and a tray icon.
- **HUD style:** Thin-line glass-cockpit look: ring progress for dwell gestures, horizontal bars for throttle/brake, an arc for steering.
