## [Unreleased]
### Added
- **M6 Handlebar & Polish:**
  - Single-hand Handlebar profile (`HandlebarProfile`) mapping wrist roll angle to steering axis ($\pm 35^\circ$), with One Euro filtering, deadzone, and expo shaping.
  - Multi-source throttle options: thumb curl, index extension, or wrist twist.
  - Off-hand brake pedal integration for two-hand motorbike control.
  - Profile import/export engine (`aileron.profiles`) with schema migrations (`schema_version = 1`), legacy v0->v1 upgrade path, and dependency-free TOML serialization.
  - Interactive onboarding flow (`OnboardingFlow`) with camera check, handedness verification, pinch practice, and safety briefing.
  - Accessibility manager (`AccessibilityManager`) with stability mode (tremor suppression, heavy smoothing, generous deadzones) and dwell click (`DwellClickDetector`, hover-to-click).
  - Dual-mode HUD overlay (`HudManager`): Compact (minimal state chips and cursor halo) and Full (telemetry, dwell rings, axis monitors).
- **M5 Cruise:**
  - Cockpit mode engine (`CockpitEngine`) coordinating simulator control profiles and mode-toggle safety gating.
  - Two-hand Yoke profile (`YokeProfile`) calculating steering wheel angle from $L_9$ vectors, with calibrated neutral subtraction, 3° deadzone, 0.35 expo curve, 45° lock-to-lock scaling, and One Euro filtering (`SIGNAL §8`).
  - Dual index-extension pedal mapping: right index throttle (`RT`) and left index brake (`LT`) with deadzone (0.05), curve shaping, and fast One Euro filtering (`SIGNAL §10`).
  - Pre-flight neutral hold (1.0 s) and axis ramp-in (200 ms) preventing sudden vehicle jumps on engage.
  - Hand-loss safety neutralization: single-hand hold for 150 ms followed by fail-safe neutralization to 0.0 or brake (`SAFE-02`).
  - Mode-toggle safety block preventing switching to Pointer mode when throttle > 0.3 (`SAFE-07`).
  - Cockpit button pinch combinations: gear up (`RB`), gear down (`LB`), handbrake (`X`), horn (`Y`).
  - Virtual gamepad backends: `VGamepadBackend` (Windows lazy import, ViGEmBus detection) and `KeyboardPwmGamepad` universal software fallback.
  - Pre-flight calibration wizard (`CalibrationWizard`) computing neutral wheel angle, lock-to-lock limits, and trigger finger range.
  - Interactive gamepad axis and trigger viewer CLI (`--gamepad-test`).
- **M4 Pressurize:**
  - Independent watchdog thread (`Watchdog`) running on dedicated OS thread, monitoring heartbeat and neutralizing backends on stall > 250 ms (`SAFE-04`).
  - Camera-stall guard (`CameraStallGuard`) monitoring frame delivery cadence and enforcing hand-lost failsafe neutralization on video stalls > 500 ms (`SAFE-04`).
  - Fail-closed central control pipeline (`ControlPipeline`) wrapping control ticks in crash boundaries, setting `FAULT`, releasing all held inputs, and dumping blackbox diagnostics (`SAFE-08`).
  - User FAULT acknowledgment recovery flow (`SessionStateManager.acknowledge_fault()`), preventing re-arming until safety status is explicitly acknowledged.
  - Event flood defense and continuous motion coalescing in `SafetyGate` (`SAFE-07`), collapsing multi-move/axis events per tick and capping discrete events.
  - In-memory circular black-box buffer (`BlackBoxRecorder`), capturing rolling landmarks and intents without pixel persistence (`PRIV-02`).
  - Comprehensive safety test suite (`tests/safety/test_safety_full.py`) verifying all `SAFE-01` through `SAFE-08` requirements.
- **M3 Climb:**
  - V-sign joystick scrolling detector (`ScrollDetector`) with hysteresis band, non-linear power curve displacement mapping (`x^1.5`), deadzone (0.15), lines/s rate limiting (60.0), hold dwell (120 ms), and cursor freeze damping (`SIG-06`).
  - Two-hand pinch zoom detector (`ZoomDetector`) with simultaneous pinch dwell (80 ms), normalized inter-hand distance metric $D$, 6% step fraction with baseline rebase, and zoom step emission (`SIG-09`).
  - Dwell gesture detector (`DwellGestureDetector`) with grace period tolerance (100 ms) for fist clutch (400 ms), palm resume/arm (400/800 ms), and shaka mode toggle (800 ms) with progress telemetry for HUD rings (`SIG-12`).
  - Session state manager (`SessionStateManager`) orchestrating states (`BOOT`, `DISARMED`, `ARMED`, `STANDBY`, `FAULT`) with safety gate synchronization and invariant `ReleaseAll()` emission on non-ARMED transitions (`SAFE-05`).
  - Mode manager (`ModeManager`) managing transitions between `POINTER` and `COCKPIT` modes with neutral frame safety guarantees and high-throttle safety locks (`SAFE-07`).
  - OpenCV HUD overlay enhancements: dwell progress indicators, cursor reticle, halo ring, and freeze state indicator.
  - Replay test suite for scroll V-sign, zoom two-hand, and clutch/resume sequences.
- **M2 Takeoff:**
  - Pinch finite state machines (`PinchLeftDetector`, `PinchRightDetector`, `PinchMiddleDetector`, `PinchGestureDetector`).
  - Left click, double click (`dbl_ms`), and drag (`tap_ms`) detection with noise spike rejection (`min_pinch_ms`).
  - Hysteresis band enforcement (`pinch_on` < `pinch_off`) preventing boundary oscillation (`TEST-01`).
  - Conflict margin separation (`margin >= 0.08`) distinguishing thumb-index from thumb-middle/ring pinches.
  - Fail-safe release of drag on hand loss (`SAFE-02`).
  - Dynamic click freeze signaling damping cursor drift during pending pinches (`SIG-06`).
  - Rate limiting cap on click event emission (`max_clicks_per_s`).
  - Top-level `GestureEngine` coordinating primary-hand tracking (`SIG-11`) with sticky lock, hand-lost timeouts, discrete detectors, and intent translation.
  - Replay test suite verifying synthesized landmark fixtures for clicks, drags, double clicks, and right clicks.
- **M1 Taxi:**
  - Scale-invariant feature extraction (`palm_size`, `anchor`, finger `curl`, `pinch` ratios, `roll_deg`, `palm_normal`).
  - 1D and 2D One Euro adaptive low-pass filter implementations (`SIG-05`).
  - Active-region cursor mapping supporting absolute (virtual desktop) and relative modes with gamma gain and click freeze damping.
  - Fail-safe `HeldInputLedger` and `SafetyGate` enforcing state gating, rate limits, and desktop clamping.
  - Windows mouse and keyboard backend (`WindowsMouseKeyboardBackend`) using native Win32 `SendInput` behind lazy import.
  - OS-level global kill switch (`KillSwitchListener`) registering `Ctrl+Alt+Esc` on dedicated thread (`SAFE-01`).
  - Filter tuning analysis tool `tools/tune_filters.py`.
- **M0 Runway:**
  - MediaPipe 21-point hand landmark named constants (`Lm`) and finger chains.
  - Core data contracts: `Frame`, `Hand`, `HandFrame`, `HandFeatures`, `Signals`, `Intent` hierarchy.
  - Pydantic v2 configuration schema and hierarchical TOML defaults loader.
  - Capture thread with single-slot latest-frame queue and horizontal mirroring.
  - MediaPipe Tasks `HandLandmarker` async tracker wrapper.
  - Safe `NullBackend` with held-input ledger and intent recording.
  - OpenCV skeleton overlay and HUD status renderer.
  - JSONL landmark recorder and replayer (`PRIV-02`).
  - Synthetic landmark generator `tools/synth_landmarks.py` and 15 standard test fixtures.
  - Latency benchmarking harness `tools/plot_latency.py` and `docs/benchmarks.md`.
  - GitHub Actions CI workflow for lint, format, type-checking, and pytest.
- Project documentation set, architecture and safety design.
